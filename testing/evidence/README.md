# DCCMP 2.0 Test Evidence

This directory is intentionally empty until actual tests are executed on your running deployment.

For each executed case, save a screenshot named `TC-<MODULE>-<NUMBER>-<description>.png` and a test-result note (date, version, expected, actual, Pass/Fail, and reviewer).

Do not use simulated or fabricated screenshots as proof of application behavior. Blur roll numbers, contact details, OTPs, passwords, and other confidential data before putting evidence into the HOD report.
